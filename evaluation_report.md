## Evaluation Report

### Models compared
- Logistic Regression
- Decision Tree

### Metrics used
Accuracy, Precision, Recall, ROC-AUC.

### Results
Both models achieved similar accuracy. Logistic Regression showed more stable and interpretable behavior.

### Calibration
Logistic Regression probabilities were better calibrated.

### Explainability
Feature coefficients from Logistic Regression were used to explain predictions.
